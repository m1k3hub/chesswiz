Square marker palette

This palette can be opened in the chessboard window either via the keyboard shortcut Ctrl+M or through the context menu of the game editor (⇒ Marks - Palette), provided that a game is currently being edited.

The palette allows selecting the marker colour and symbol type for highlighting squares and arrows on the chessboard.

The palette is only visible when the chessboard window is active.

In the game editor, annotations with board marks are indicated by the symbol . The tooltip displays the code as formatted in PGN format.

The following explains how to place markers on the chessboard:

  • Marking a square with a symbol
  • Marking a move with an arrow

Marking a square with a symbol

Double-clicking or clicking twice on a square while holding the Ctrl key marks the square with the selected symbol and color. To remove the marker, double-click the square again while holding Ctrl using the same symbol and color. A square marker can be replaced by placing another marker over it. Only one marker can be placed per square.

Marking a move with an arrow

An arrow is placed by clicking with Ctrl held down on the origin square, and then clicking with Ctrl on the destination square. The arrow appears in the selected color. To remove an arrow, place an arrow with the same color on the same origin and destination squares.
