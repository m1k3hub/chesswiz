Advanced Search

Advanced Search filters the games of one database. Combine any of the fields; an empty field is ignored. The result list below shows the matching games, and the title bar shows the active filter.

  • Player and Player side: a player playing either colour, White only or Black only. A plain surname such as Carlsen also finds Carlsen, Magnus.
  • Event, Site, Annotator: names of the event, site and annotator.
  • Position ID: the start position of the game. Use Start Position takes it from the current game.
  • Rating, Mode, Range: a rating type and a range such as 2200 or 2000-2400, for White, Black, the average of both, or White and Black separately (second range).
  • Material: Q/R/B/N letters plus the pawn count for White and Black, such as qrbn8. The mode matches exactly, the same majors and minors, or a pawn count range such as 5-7.

In name fields, * matches any text and ? one character. Prefix a name with = to match it literally.

Search (or Return) runs the search, Reset clears all fields. Open In Switcher shows the matching games in the database switcher, and Save Working Set... stores them under a name. Presets save and reload a set of field values.
