Comment editor

The comment editor allows entering and editing move comments, text annotations, and evaluations. The dialog can be opened in several ways:

  • With the keyboard shortcut Ctrl+C to edit the comment after the current move.
  • With the keyboard shortcut Ctrl+Shift+C to edit a comment before the move, or a leading comment of a variation when the cursor is at the start of a variation.
  • Via the context menu of the game editor.
  • By clicking on an existing comment in the notation view. In this case, the editor automatically switches to the language of the selected comment.

The comment editor is available whenever a game is open for editing.

The dialog is organized into five main areas:

  • Language selection (top toolbar)
  • Text formatting (left toolbar)
  • Text field
  • Text control buttons (buttons to the right of the text field)
  • Dialog buttons (bottom buttons)

Language selection

The comment editor supports multi-language commentary in games. You can maintain commentaries in multiple languages within the same game. Click to add another language tab.

Text formatting

Comments can be formatted with rich text styles:

  •  Bold
  •  Italic
  •  Underline

Any combination of these styles can be applied. Select a text region (⇒ Text navigation & control) and click the desired style button. The style applies to the entire selection. When typing, new characters continue the style of the text immediately preceding the insertion cursor.

Figurines (graphical piece symbols such as ♔) and evaluation marks (such as ±) are not affected by italic or underline formatting.

Rich text styles are preserved in native .sci databases. When exporting to standard PGN format or plain text, text styling is converted or stripped according to the selected export options.

Recognized NAG annotation symbols are highlighted in dark red. Hovering the mouse over a symbol displays a tooltip with its meaning.

Mouse navigation

Clicking with the left mouse button places the insertion cursor at the clicked position, focuses the text field, and clears any existing selection. Dragging with the left button held down selects the text between the anchor and the cursor.

Double-clicking selects the word under the pointer. Dragging after a double click extends the selection by whole words.

Triple-clicking selects the entire line. Dragging after a triple click extends the selection by whole lines.

Clicking the left mouse button while holding Ctrl moves the insertion cursor without modifying the current text selection.

Dragging with the middle mouse button scrolls the text view. Clicking the middle mouse button pastes the primary selection (X11 / Linux).

Text selection

Standard selection shortcuts are supported: Ctrl+A selects all text in the editor. Holding Shift while moving the cursor extends the selection.

Deleting text

⟻ deletes the character before the cursor; Delete or Ctrl+D deletes the character after the cursor. Ctrl+⟻ or Ctrl+Delete deletes the word before or after the cursor. When text is selected, pressing any deletion key removes the selected range.

Undo & Redo

Ctrl+Z undoes the last editing action. Ctrl+Y or Ctrl+Shift+Z redoes previously undone changes.

Additional shortcuts

Standard clipboard shortcuts Ctrl+C (copy), Ctrl+X (cut), and Ctrl+V (paste) are supported throughout the editor.

Special characters

Special chess evaluation marks (such as !?, =+, ±) can be entered quickly via the context menu or using the symbol insertion button.

Hyperlinks

The comment editor allows inserting web hyperlinks and clickable email addresses using simple wiki-style syntax:

  1. [[https://chesswizapp.com]] creates a link displaying the URL https://chesswizapp.com .
  2. [[https://chesswizapp.com][Chesswiz]] creates a link with custom text: Chesswiz . Alternatively, the syntax [[https://chesswizapp.com|Chesswiz]] can be used.
  3. [[mailto:user@example.com][Contact]] creates an email link to Contact .

A helper tool for inserting links is also available in the context menu.

Smileys

When emoticon display is enabled, standard text smilies (such as :-)) are rendered as graphical pictograms (). Emoticons can be inserted directly from the context menu.

Context menu

Right-clicking in the text field opens the context menu with shortcuts for:

  • Cut / Copy / Paste – Standard clipboard actions.
  • Insert Symbol – Insert evaluation marks and special annotations.
  • Insert Emoticon – Insert graphical smilies.
  • Insert Link – Insert a formatted hyperlink.
  • Format Text – Apply bold, italic, or underline to selected text.
  • Copy Text to Language – Copy commentary to another language tab.
  • Undo / Redo – History navigation.
  • Select All / Clear – Select or clear entire text.
  • Revert – Discard unsaved changes and restore initial text.
  • Switch / Add Language – Manage multi-language commentary.

Text control buttons

Buttons located to the right of the text field provide quick access to:

  • Insert Symbol – Open the symbol picker.
  • Clear – Clear all text in the active language tab.
  • Revert – Restore original text since last save.

Dialog buttons

  • OK – Save commentary across all languages and close dialog.
  • Apply – Save commentary immediately to preview changes in notation without closing.
  • Cancel – Close dialog discarding unapplied changes.
