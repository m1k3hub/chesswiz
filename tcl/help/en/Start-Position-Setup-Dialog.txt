INDEX Edit start position
TITLE Edit start position

<p>
This dialog simplifies setting up a Chess 960 (Fischer Random) or
Shuffle Chess starting position. You simply place the pieces along
White's back rank. The %::mc::OK% button is enabled only when a valid
starting position has been entered. If the identification number of
the start position is already known, the
<a href="Board-Setup-Dialog.html">Board Setup dialog</a> can be used
instead to enter the position number directly.
</p>
