Welcome to Chesswiz!

Welcome to Chesswiz 1.0! Here are a few important things to know:

  1. The native database format (.sci) was designed by Gregor Cramer for Scidb; Chesswiz adds modern features, AI capabilities, and expanded multimedia support.
  2. Support for proprietary external formats (.cbh/.cbg) includes reading games with annotations, media playback, and move-exact Chess 960 decoding.

Have a lot of fun with Chesswiz, which is built on Scidb, whose development began in 2008.

What Chesswiz adds

  • An assistant you talk to in plain language: ask why a game was lost, what a player usually plays, or how to prepare for an opponent, and it answers on the board (Main Menu > Extras > AI: Assistant). The AI features use a cloud model you choose under AI: Choose Model.
  • Analysis with strong engines: Stockfish is included and ready to use, and further UCI and WinBoard engines can be added (Main Menu > Setup > Engines).
  • A 3D board alongside the 2D board (Main Menu > Extras > Open 3D Board).
  • The keyboard shortcuts you may already know: switch to the traditional shortcut scheme under Main Menu > Setup > Keyboard Preferences.
  • Export to PGN, native (.sci), legacy formats, PDF, HTML and LaTeX, and tournament tables from the game list.
  • The same program on Windows, macOS and Linux.

What Chesswiz is good for right now

  • Managing and browsing Chesswiz databases (.sci) with a database switcher, sortable game lists, player/event/site views, and game browser/editor workflows.
  • Running database-first workflows on .sci databases, including filtered views, working sets, database maintenance, duplicate detection, and opening statistics.
  • Searching: Main Menu > Search (or the magnifier on the database toolbar) offers a plain-language search (for example "Carlsen's losses as Black since 2015"), advanced search by header and position, searches by material and by rating, duplicate detection, and CQL 6.2 for specialised pattern queries.
  • Opening preparation from the players list: player prep reports summarize recent games, white/black opening tendencies, and repertoire coverage.
  • Opponent preparation with an opponent dossier: recent games, opening tendencies, filtered prep pivots, switcher views, and working-set creation are available directly from the dossier.
  • Importing and exporting practical formats such as PGN, FEN, and EPD, with .sci conversion recommended for repeated analysis and maintenance work.
  • Reading external multimedia databases (.cbh/.cbg) with annotations, Chess 960 archives, and media manifests (.cbm): the media panel lists each magazine section's pictures, audio, and videos.
  • The media panel plays media embedded in the application (images via the built-in viewer, audio/video via an in-process player), with the board following the video and the video following the board (Chess Media System semantics).
  • Interactive multimedia lessons (.cms indexes plus position-keyed clips) are supported: entering a position on the board jumps to the matching video clip.
  • Multimedia magazine reports (guiding texts) are rendered in a built-in HTML viewer - navigation, diagrams, and video stills included - with game links and media links clickable.
  • Native HTML support: open HTML documents directly (safely sanitized before display), and publish games as standalone HTML files with tag tables, variations, comments, and inline SVG diagrams - viewable in any browser.

Useful media how-tos

Watch a magazine section with its videos

  1. Open an external multimedia database (for example a section with its .cbm manifest and .html media folder).
  2. Load the section's report game (the guiding-text entry) - the media panel fills with that section's media.
  3. Double-click a video to play it with the board following the narration; step the board to jump inside the lesson.
  4. Open the section report with "View report" to browse the magazine page; clicking a game link loads that game.

Publish a game as HTML

  1. Select Export in the database or game bar menu and pick the HTML type.
  2. The exported file is standalone (embedded styles, inline-SVG diagrams) and opens in any browser.

Useful prep how-tos

Build a player prep report

  1. Open a Chesswiz database, then go to the players list and select the player you want to study.
  2. Open the player prep report from the players area.
  3. Use the white or black opening tables to filter the recent games list to one opening family.
  4. Use the recent games area to open a game, jump to the opponent's prep report, or open the opponent dossier.

Find repertoire gaps and save them

  1. Open the player prep report for your target player.
  2. Look at the open repertoires section to see which repertoire databases match the player's top openings.
  3. Use "Open First Gap", "Open First Gap In Switcher", or "Save First Gap Working Set..." to turn an uncovered opening into a concrete review list.

Use the opponent dossier as a prep hub

  1. From a prep report, open the opponent dossier for the selected player.
  2. Use the white and black opening tables to inspect tendencies, then open the selected line in a prep report or switcher view, or save it as a working set.
  3. Use the recent games table to open a game, jump to the opponent's prep report, open the opponent's own dossier, or save that opponent's games as a working set.
