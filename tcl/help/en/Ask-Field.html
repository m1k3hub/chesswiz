The Ask Field and Assistant

The Ask field in the top strip provides quick access to actions and commands across Chesswiz. It combines a fast action palette, natural language requests, and optional local speech input in a single field.

The Ask field

The Ask field is located in the top strip of the main window notebook, immediately to the left of the main drop-down menu. It functions as the application's action palette directly within the main window, with no need for a separate palette dialog.

When the field is empty, a light gray placeholder text displays: "Ask or tell Chesswiz what to do (Ctrl+K)". As soon as you begin typing, the placeholder disappears and the result list opens below the field. When the field is empty, pressing Up or Down steps through your recent request history.

Action palette and result list

Typing in the Ask field filters Chesswiz's action registry on every keystroke. Only runnable actions are displayed: an action appears only if it is currently both enabled and visible according to the active application state (matching the same rules as the main drop-down menu).

Matching actions are ranked by fuzzy matching across their labels, documentation, and keyboard shortcuts. Each entry displays:

  • The descriptive action label.
  • The keyboard shortcut assigned to that action, if any.

You can navigate and execute items from the result list:

  • Up and Down arrows move the selection up and down the list.
  • Return or KP_Enter (or a mouse click) executes the selected action. The command runs through the action runner, which ensures all safety gates and confirmation prompts apply.
  • Escape closes the result list and restores focus to the widget that had focus previously (such as the chessboard).

The final entry in the result list is always Ask the assistant. Selecting this entry, or pressing Return on any query that does not match a registered action, sends the query text directly to the Assistant.

Speech input

A microphone button labeled Speak sits on the right side of the Ask field. Clicking the button records speech, transcribes it locally, and inserts the transcribed text directly at the cursor in the Ask field.

Speech is strictly an input mechanism: Chesswiz never generates speech output. The transcribed text remains completely editable in the field and is never sent or executed until you explicitly press Return.

All speech processing is performed locally using external tools without external network services or linked audio libraries:

  • Linux: Uses whisper.cpp's whisper-cli (CPU-only execution) along with arecord or ffmpeg.
  • Windows: Uses the operating system's built-in dictation (Win+H).
  • macOS: Uses system dictation (configured in System Settings > Keyboard > Dictation).

If no speech tool or model is detected, the microphone button is automatically hidden from the interface. You can configure local speech paths in Preferences > Assistant (or action app.preferences.assistant), which provides settings for the whisper-cli path, model file, and recording tool, along with a Detect button to verify the configuration.

Keyboard shortcuts

The Ask field is easily accessible from anywhere in Chesswiz using keyboard shortcuts:

  • Ctrl+K: Focuses the Ask field and selects all its text, ready for immediate typing. In multi-line text editing widgets (such as the Comment Editor, PGN text, or engine console), Ctrl+K preserves the standard editing command to delete from the cursor to the end of the line.
  • Ctrl+Shift+K: Unconditionally focuses the Ask field from anywhere in the application, including from within multi-line text editors.
  • Escape: Dismisses the result list and returns focus to the previous control or chessboard.

The Assistant

The Assistant is an automated operator that drives Chesswiz's registered actions from plain language requests. It is docked in the Assistant pane of the Board tab (and can be docked or undocked like any board pane; pressing F2 brings it into view).

You can ask the Assistant to perform operations in your own words, such as finding games, setting up board positions, generating player preparation reports, opening searches, or explaining the current position.

Key design principles of the Assistant include:

  • Drives registered actions: The Assistant cannot execute arbitrary operations. It is constrained to Chesswiz's fixed registry of actions and tools, and all parameters are validated against formal schemas before any command is called.
  • Multi-step plans with one confirmation: When a complex request requires multiple steps, the Assistant presents them as a unified plan. If any step modifies data, imports games, or performs bulk changes, Chesswiz asks for one confirmation covering the entire plan. If declined, no actions are run. If any step encounters an error, execution stops immediately while preserving earlier successful steps. Any dialog opened during a plan pauses execution until dismissed.
  • Never required: The Assistant is strictly a convenience operator. Every single action, search, dialog, and tool in Chesswiz is directly reachable through the application menus, toolbars, and keyboard shortcuts. Proficient users can operate every feature of Chesswiz without ever opening or using the Assistant.
