<h2 id="Homepage">Contact</h2>

Questions, bug reports and feature requests about Chesswiz go to
<a href="mailto:thomas.g.mike+chesswiz@gmail.com">thomas.g.mike+chesswiz@gmail.com</a>.

<h2>Help</h2>

Volunteers are welcome for:

<ul>
  <li>Testing Chesswiz</li>
  <li>Translation into other languages</li>
  <li>Writing help pages</li>
</ul>

Please send a message to the address above, so that these tasks
can be coordinated.

<h2>Links</h2>
  
<p>
Chesswiz users may find the following websites interesting:
</p>

<ul>
  <li><p>
    <a href="ftp://ftp.cis.uab.edu/pub/hyatt/"
       style="line-height: 150%;">
    ftp://ftp.cis.uab.edu/pub/hyatt/</a><br/>
    The legendary chess engine Crafty. The subdirectory there named TB has many
    Nalimov-format tablebase files that you can use in several chess programs and
    in Chesswiz. 
  </p></li>

  <li><p>
    <a href="http://tablebase.sesse.net"
       style="line-height: 150%;">
    tablebase.sesse.net</a><br/>
    This site does also provide tablebase files, including 6-men bases.
  </p></li>

  <!--<li><p>
    <a href="http://folk.uib.no/pfvaf/chesslib/Nalimov.htm">
       style="line-height: 150%;">
    ChessliB - Nalimov's endgame tablebases</a><br/>
    Another site with tablebase files (3-4-5).
  </p></li>-->

  <li><p>
    <a href="http://www.theweekinchess.com"
       style="line-height: 150%;">
    The Week in Chess</a><br/>
    An excellent weekly bulletin of international chess games in available
    in <abbr>PGN</abbr> format. 
  </p></li>

  <li><p>
    <a href="http://www.saremba.de/chessgml/standards/pgn/pgn-complete.htm"
       style="line-height: 150%;">
    Standard: Portable Game Notation Specification and Implementation Guide</a><br/>
    The <abbr>PGN</abbr> Standard, created by Steven J. Edwards in 1994. This website
    explains the <abbr>PGN</abbr> and <abbr>EPD</abbr> formats in detail.
  </p></li>

  <li><p>
    <a href="http://en.wikipedia.org/wiki/ECO_code"
       style="line-height: 150%;">
    ECO-Code</a><br/>
    An overview about the ECO code.
  </p></li>
</ul>
