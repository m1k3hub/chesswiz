TITLE Welcome to Chesswiz!

<p>
This is a preliminary version of Chesswiz for try-out and testing. The first
full version will be released after a sufficiently long test period. Please
consider when experimenting with Chesswiz:
</p>

    games are read with annotations, and Chess 960 archives are decoded

    From time to time a newer test version will be released.
  </li>
</ol>

Have a lot of fun with Chesswiz, which is built on Scidb, whose development began in 2008.
</p>

<h2>What Chesswiz adds</h2>

<ul style="padding: 5px;">
  <li class="space">An assistant you talk to in plain language: ask why a game was lost, what a player usually plays, or how to prepare for an opponent, and it answers on the board (<b>Main Menu &gt; Extras &gt; AI: Assistant</b>). The AI features use a cloud model you choose under <b>AI: Choose Model</b>.</li>
  <li class="space">Analysis with strong engines: Stockfish is included and ready to use, and further UCI and WinBoard engines can be added (<b>Main Menu &gt; Setup &gt; Engines</b>).</li>
  <li class="space">A 3D board alongside the 2D board (<b>Main Menu &gt; Extras &gt; Open 3D Board</b>).</li>
  <li class="space">The keyboard shortcuts you may already know: switch to the ChessBase-style scheme under <b>Main Menu &gt; Setup &gt; Keyboard Preferences</b>.</li>
  <li class="space">Export to PGN, Scidb, Scid, PDF, HTML and LaTeX, and tournament tables from the game list.</li>
  <li class="space">The same program on Windows, macOS and Linux.</li>
</ul>

<h2>What Chesswiz is good for right now</h2>

<ul style="padding: 5px;">
  <li class="space">Managing and browsing Chesswiz databases (<abbr>.sci</abbr>) with a database switcher, sortable game lists, player/event/site views, and game browser/editor workflows.</li>
  <li class="space">Running database-first workflows on <abbr>.sci</abbr> databases, including filtered views, working sets, database maintenance, duplicate detection, and opening statistics.</li>
  <li class="space">Searching: <b>Main Menu &gt; Search</b> (or the magnifier on the database toolbar) offers a plain-language search (for example "Carlsen's losses as Black since 2015"), advanced search by header and position, searches by material and by rating, duplicate detection, and CQL 6.2 for specialised pattern queries.</li>
  <li class="space">Opening preparation from the players list: player prep reports summarize recent games, white/black opening tendencies, and repertoire coverage.</li>
  <li class="space">Opponent preparation with an opponent dossier: recent games, opening tendencies, filtered prep pivots, switcher views, and working-set creation are available directly from the dossier.</li>
  <li class="space">Importing and exporting practical formats such as PGN, FEN, and EPD, with <abbr>.sci</abbr> conversion recommended for repeated analysis and maintenance work.</li>
  <li class="space">Reading ChessBase databases (<abbr>.cbh</abbr>/<abbr>.cbg</abbr>) with annotations, Chess 960 archives, and media manifests (<abbr>.cbm</abbr>): the media panel lists each magazine section's pictures, audio, and videos.</li>
  <li class="space">The media panel plays media embedded in the application (images via the built-in viewer, audio/video via an in-process player), with the board following the video and the video following the board (Chess Media System semantics).</li>
  <li class="space">Interactive ChessBase lessons (<abbr>.cms</abbr> indexes plus position-keyed clips) are supported: entering a position on the board jumps to the matching video clip.</li>
  <li class="space">ChessBase magazine reports (guiding texts) are rendered in a built-in HTML viewer - navigation, diagrams, and video stills included - with game links and media links clickable.</li>
  <li class="space">Native HTML support: open HTML documents directly (safely sanitized before display), and publish games as standalone HTML files with tag tables, variations, comments, and inline SVG diagrams - viewable in any browser.</li>
</ul>

<h2>Useful media how-tos</h2>

<h3>Watch a magazine section with its videos</h3>

<ol>
  <li class="space">Open a ChessBase magazine database (for example a CBM section with its <abbr>.cbm</abbr> manifest and <abbr>.html</abbr> media folder).</li>
  <li class="space">Load the section's report game (the guiding-text entry) - the media panel fills with that section's media.</li>
  <li class="space">Double-click a video to play it with the board following the narration; step the board to jump inside the lesson.</li>
  <li class="space">Open the section report with "View report" to browse the magazine page; clicking a game link loads that game.</li>
</ol>

<h3>Publish a game as HTML</h3>

<ol>
  <li class="space">Select Export in the database or game bar menu and pick the HTML type.</li>
  <li class="space">The exported file is standalone (embedded styles, inline-SVG diagrams) and opens in any browser.</li>
</ol>

<h2>Useful prep how-tos</h2>

<h3>Build a player prep report</h3>

<ol>
  <li class="space">Open a Chesswiz database, then go to the players list and select the player you want to study.</li>
  <li class="space">Open the player prep report from the players area.</li>
  <li class="space">Use the white or black opening tables to filter the recent games list to one opening family.</li>
  <li class="space">Use the recent games area to open a game, jump to the opponent's prep report, or open the opponent dossier.</li>
</ol>

<h3>Find repertoire gaps and save them</h3>

<ol>
  <li class="space">Open the player prep report for your target player.</li>
  <li class="space">Look at the open repertoires section to see which repertoire databases match the player's top openings.</li>
  <li class="space">Use "Open First Gap", "Open First Gap In Switcher", or "Save First Gap Working Set..." to turn an uncovered opening into a concrete review list.</li>
</ol>

<h3>Use the opponent dossier as a prep hub</h3>

<ol>
  <li class="space">From a prep report, open the opponent dossier for the selected player.</li>
  <li class="space">Use the white and black opening tables to inspect tendencies, then open the selected line in a prep report or switcher view, or save it as a working set.</li>
  <li class="space">Use the recent games table to open a game, jump to the opponent's prep report, open the opponent's own dossier, or save that opponent's games as a working set.</li>
</ol>
