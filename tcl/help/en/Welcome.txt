TITLE Welcome to Scidb!

<p>
This is a preliminary version of Scidb for try-out and testing. The first
full version will be released after a sufficiently long test period. Please
consider when experimenting with Scidb:
</p>

<ol>
  <li class="space">
    This version contains a lot of debugging information and is accordingly
    slow in several places.
  </li>

<!--
  <li class="space">
    The support of Scid databases (.si3/.si4) is performed by a quite complex
    emulation which is not yet sufficiently tested.
	  <annotation>
    Therefore please do not edit your original Scid databases with this program.
    </annotation>
    Per default the Scid databases will be opened in read-only mode, which is
    of course uncritical.
  </li>
-->

  <li class="space">
    The current Scidb format (.sci) will be finished at latest with the first
    full version (i.e. it will reach version 1.0 later, the current version
    is 0.94). Nevertheless the current format is already fully usable, and there
    will be offered an upgrade capability.
  </li>

  <li class="space">
    The support of the ChessBase format (.cbh) is not yet finished. Currently
    this application cannot open Chess 960 games.
  </li>

  <li class="space">
    From time to time a newer test version will be released.
  </li>
</ol>

<p>
Have a lot of fun with Scidb, whose development has already taken nine years!
</p>

<h2>What Scidb is good for right now</h2>

<ul style="padding: 5px;">
  <li class="space">Managing and browsing Scidb databases with a database switcher, sortable game lists, player/event/site views, and game browser/editor workflows.</li>
  <li class="space">Running database-first workflows on <abbr>.sci</abbr> databases, including filtered views, working sets, database maintenance, duplicate detection, and opening statistics.</li>
  <li class="space">Searching by position and material, and using CQL for more specialized pattern queries.</li>
  <li class="space">Opening preparation from the players list: player prep reports summarize recent games, white/black opening tendencies, and repertoire coverage.</li>
  <li class="space">Opponent preparation with an opponent dossier: recent games, opening tendencies, filtered prep pivots, switcher views, and working-set creation are available directly from the dossier.</li>
  <li class="space">Importing and exporting practical formats such as PGN, FEN, and EPD, with <abbr>.sci</abbr> conversion recommended for repeated analysis and maintenance work.</li>
</ul>

<h2>Useful prep how-tos</h2>

<h3>Build a player prep report</h3>

<ol>
  <li class="space">Open a Scidb database, then go to the players list and select the player you want to study.</li>
  <li class="space">Open the player prep report from the players area.</li>
  <li class="space">Use the white or black opening tables to filter the recent games list to one opening family.</li>
  <li class="space">Use the recent games area to open a game, jump to the opponent's prep report, or open the opponent dossier.</li>
</ol>

<h3>Find repertoire gaps and save them</h3>

<ol>
  <li class="space">Open the player prep report for your target player.</li>
  <li class="space">Look at the open repertoires section to see which repertoire databases match the player's top openings.</li>
  <li class="space">Use "Open First Gap", "Open First Gap In Switcher", or "Save First Gap Working Set..." to turn an uncovered opening into a concrete review list.</li>
</ol>

<h3>Use the opponent dossier as a prep hub</h3>

<ol>
  <li class="space">From a prep report, open the opponent dossier for the selected player.</li>
  <li class="space">Use the white and black opening tables to inspect tendencies, then open the selected line in a prep report or switcher view, or save it as a working set.</li>
  <li class="space">Use the recent games table to open a game, jump to the opponent's prep report, open the opponent's own dossier, or save that opponent's games as a working set.</li>
</ol>
