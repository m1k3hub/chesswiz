<h2 id="Homepage">Kontakt</h2>

Fragen, Fehlerberichte und Wünsche zu Chesswiz bitte an
<a href="mailto:thomas.g.mike+chesswiz@gmail.com">thomas.g.mike+chesswiz@gmail.com</a>.

<h2>Mithilfe</h2>

Freiwillige sind willkommen für:

<ul>
  <li>Testen von Chesswiz</li>
  <li>Übersetzung in weitere Sprachen</li>
  <li>Schreiben von Hilfeseiten</li>
</ul>

Bitte eine Nachricht an die obige Adresse senden, damit diese
Aufgaben koordiniert werden können.

<h2>Links</h2>
  
<p>
Für Chesswiz-Benutzer könnten folgende Seiten interessant sein:
</p>

<ul>
  <li><p>
    <a href="ftp://ftp.cis.uab.edu/pub/hyatt/"
       style="line-height: 150%;">
    ftp://ftp.cis.uab.edu/pub/hyatt/</a><br/>
    Das legendäre Schachprogram Crafty. Das TB - Unterverzeichnis beinhaltet fast alle
    Nalimov-Endspieltabellen, welche von einigen Schachprogrammen und auch von
    Chesswiz (in einer zukünftigen Version) benutzt werden. 
  </p></li>

  <li><p>
    <a href="http://tablebase.sesse.net"
       style="line-height: 150%;">
    tablebase.sesse.net</a><br/>
    Diese Seite bietet ebenfalls Endspieltabellen an, unter anderem auch Sechssteiner.
  </p></li>

  <!--<li><p>
    <a href="http://folk.uib.no/pfvaf/chesslib/Nalimov.htm">
       style="line-height: 150%;">
    ChessliB - Nalimov's endgame tablebases</a><br/>
    Eine weitere Seite mit Endspieltabellen (3-4-5).
  </p></li>-->

  <li><p>
    <a href="http://www.theweekinchess.com"
       style="line-height: 150%;">
    The Week in Chess</a><br/>
    Ein hervorragendes Wochenmagazin für internationale Schachpartien, das
    <abbr>PGN</abbr> Dateien für den Download bereitstellt.
  </p></li>

  <li><p>
    <a href="http://www.saremba.de/chessgml/standards/pgn/pgn-complete.htm"
       style="line-height: 150%;">
    Standard: Portable Game Notation Specification and Implementation Guide</a><br/>
    Der <abbr>PGN</abbr>-Standard, geschaffen von Steven J. Edwards im Jahre 1994. Die Webseite
    erklärt das <abbr>PGN</abbr>- und <abbr>EPD</abbr>-Format im Detail.
  </p></li>

  <li><p>
    <a href="http://de.wikipedia.org/wiki/ECO-Codes"
       style="line-height: 150%;">
    ECO-Code</a><br/>
    Eine Übersicht über den ECO-Schlüssel.
  </p></li>
</ul>
